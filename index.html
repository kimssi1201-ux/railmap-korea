레일맵은 출발역·도착역의 운행시간표를 한곳에서 찾아보도록 만든 독립 서비스입니다.

데이터 연결 전: 주요 역의 참고 위치와 즐겨찾기·검색 화면을 체험할 수 있으며 시간표를 임의로 만들어 표시하지 않습니다.

API 연결 후: 국토교통부 TAGO의 날짜별 열차 운행정보를 조회합니다. 운임은 API 제공 시 표시하며 좌석 잔여·실시간 지연 정보는 제공하지 않습니다.

타는 곳: 공식 TAGO 열차 시간표에는 개별 열차의 승강장 번호가 없어 현장 출발 전광판과 역 직원의 안내를 확인해야 합니다. 검색 결과의 ‘탑승 안내’를 누르면 찾는 순서를 볼 수 있습니다.

예매: 결제·발권은 철도운영사의 공식 페이지를 이용합니다. 노선과 정차역은 검색 결과에서 확인하세요.
