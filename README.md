# RAILMAP — 전국 기차 시간표 간편 검색

기존 `train` 지하철 프로젝트와 별개의 Cloudflare Pages 사이트. **지도 라이브러리/타일은 제거**하고 출발역·도착역·날짜 중심의 모바일 퍼스트 검색 UI를 제공합니다.

## 구현 기능
- 공식 국토교통부 TAGO 열차정보 API로 전국 역 목록 및 출발/도착 구간별 직통 열차 시간표 조회
- KTX·SRT·일반열차 필터 및 출발시간·소요시간·제공 운임 정렬
- 자주 찾는 구간, 최근 검색 구간(기기 내 저장), 출발·도착 바꾸기
- 열차별 공식 예약처 연결, 승강장 현장 확인 안내
- 320px 이상 모바일의 가로 스크롤 없는 반응형 웹

## Cloudflare Pages
- GitHub 저장소: `kimssi1201-ux/railmap-korea`
- 프로젝트: `railmap-korea`
- Production 브랜치: `main`
- Framework preset: `None` / Build command: 비워두기 / Output directory: `.`
- Secret `TAGO_API_KEY`: 공공데이터포털 TAGO 열차정보 활용 신청 후 Cloudflare Pages Production 환경변수로 보관. GitHub에 키 업로드 금지.
- `git push origin main`에 따른 Cloudflare 자동 배포 사용. 직접 배포 CLI 금지.

## 개발/검증
- `npm run build`: JS 구문 검사
- `npm test`: API 및 승강장 응답 검사
- 실제 공공데이터 API 연결은 키/공급기관 응답이 필요합니다. 실시간 좌석·결제·발권·지연·열차별 승강장 번호는 제공하지 않습니다.
- 역 목록 실패 시 시간표를 임의로 생성하지 않습니다. 실제 열차시간표는 `/api/trains` 결과로만 표시합니다.

## 승강장 주의
TAGO는 당일 열차별 승강장 번호를 제공하지 않습니다. 화면은 공식 자료로 확인할 수 없는 번호를 추정하지 않고 `현장 확인 필요`라고 안내합니다.


## 고속·시외버스 시간표 (버스 v1)
- 메인 `/`은 기존 기차 검색을 유지하며, 상단 탭에서 `/bus.html?type=express` (고속버스), `/bus.html?type=intercity` (시외버스)로 이동합니다.
- Cloudflare Pages Functions: `GET /api/bus-terminals?type=express|intercity` 와 `GET /api/bus-timetables?type=express|intercity&from=<terminalID>&to=<terminalID>&date=YYYY-MM-DD`.
- 공공데이터포털 활용 승인: [고속버스](https://www.data.go.kr/data/15098522/openapi.do)와 [시외버스](https://www.data.go.kr/data/15098541/openapi.do)를 각각 승인해야 합니다.
- 환경 비밀변수: 기존 `TAGO_API_KEY`를 우선 재사용할 수 있으며, 별도 발급키가 있다면 `EXPBUS_API_KEY` 및 `SUBURBSBUS_API_KEY`를 설정할 수 있습니다. API 키를 저장소에 넣지 마세요.
- 시외버스는 공공데이터포털 안내에 따라 **당일 배차만 조회**하도록 클라이언트와 서버 양측에서 제한했습니다.
- 실제 좌석 수, 구매 가능 여부, 미제공 운임 및 배차를 임의로 만들어 표시하지 않습니다. 예매는 공식 예매 사이트로 이동합니다.
- `npm run build && npm test`로 검사합니다. 실제 인증키로 된 라이브 공공데이터 응답 검증은 별도로 수행해야 합니다.
## 전국 시내버스 정보 (1차)
- `/citybus.html`: TAGO 제공 지역 목록과 선택, 정류장명/번호 검색, 노선번호 검색, 경유 정류장, 실시간 도착정보, 기기 내 즐겨찾기.
- 지역별 시내버스 API: 정류소정보(15098534), 노선정보(15098529), 도착정보(15098530) 각 활용신청 필요. TAGO 기존 키가 모든 API에서 허가되지 않을 수 있음.
- Production Secret: 기본 `TAGO_API_KEY` 우선 활용. 별도 키면 `CITYBUS_STOPS_API_KEY`, `CITYBUS_ROUTES_API_KEY`, `CITYBUS_ARRIVALS_API_KEY` 등록 가능. 비밀키는 클라이언트/GitHub에 노출 금지.
- GET `/api/citybus-areas`, `/api/citybus-search?city=25&kind=stops&q=시청`, `/api/citybus-arrivals?city=25&id=...`, `/api/citybus-route?city=25&id=...`.
- 도착예정은 TAGO 지역별 지원 범위에 한정. 실시간 데이터는 최대 25초 캐시, 사용자가 누를 때만 갱신하고 자동 반복 호출하지 않음. 미제공 시간·노선/정류장 정보는 추정하지 않음.
- 지역별 링크는 `/citybus.html?city=<TAGO-citycode>`; 공공데이터를 확인하지 않은 별도 지역 콘텐츠를 대량 생성하지 않음.

## 2026-10-23 검색 정확도 개선
- 열차: TAGO 시간표를 최대 5페이지(페이지당 300건)까지 조회하고, 중간 응답 실패 시 기존 검증 결과와 `partial` 표시를 유지합니다.
- 시내버스: 첫 페이지 검색 결과가 비어도 API가 다음 페이지를 제공하면 더 보기를 유지하고, 지역 변경 시 이전 지역의 결과와 진행 중인 검색을 무효화합니다.
- 버스/시내버스 라이브 응답 품질은 연결된 Cloudflare Production Secret과 운영 지역의 TAGO 제공 상태를 통한 실측 검증이 필요합니다.

## 지역별 고속·시외버스 터미널 목록
- 고속·시외버스 페이지의 지역별 터미널 찾기 메뉴에서 17개 시·도 → 시·군 → 출발/도착 순서로 탐색할 수 있습니다.
- 원본 TAGO 터미널 API에는 모든 터미널의 검증된 주소/시·도가 제공되지 않으므로 공식 표시명으로 확인할 수 있는 지역만 분류합니다. 알 수 없거나 동명이 지역명은 임의로 배정하지 않고 기존 전국 이름 검색에 남깁니다.
- `/bus.html?type=express&region=전북` 형태로 지역별 목록을 열 수 있습니다. 기존 버스 조회 API와 코드별 노선 검색 결과는 변경하지 않았습니다.

## 시간표 표형 검색결과
- 기차 및 고속·시외버스 검색결과를 모바일 4열 표로 비교합니다. 열차번호·열차종류·출발·도착·요금을 공식 API 응답에서만 표시합니다.
- 각 행의 열차번호 또는 출발시간을 눌러 소요시간, 승강장 안내(기차), 공식 예매 링크를 확인할 수 있습니다.
- TAGO에서 중간 정차역별 시각을 제공하지 않으므로 역별 시간표 행렬은 만들지 않고 조회한 직통 구간만 표시합니다.

## 지역별 기차역과 구간 상세페이지 1차 (2026-10-23)
- 모노알다의 탐색 구조만 참고하고 독립 디자인과 문구로 기차역 10곳 및 추천 구간 13쌍의 양방향 상세페이지를 구축했습니다.
- /stations/ : 지역별 역 목록. /stations/:id : 주요역 상세 안내. /routes/:from/:to : 날짜별 TAGO 공식 직통 시간표 조회.
- 요일별 고정 시간표, 확인되지 않은 운임, 중간 정차시간을 임의 생성하지 않습니다. 구간 링크는 직통 운행 확정이 아니라 조회 제안입니다.
- Cloudflare Pages Functions는 dynamic segments를 사용하여 서버에서 고유 제목·설명·canonical을 제공하며 존재하지 않는 경로는 404를 반환합니다.
- sitemap.xml, robots.txt 구성. live TAGO API 및 Cloudflare 배포 상태는 별도로 검증해야 합니다.

## 전국 17개 시·도 기차역 목록 확장 (2026-10-23)
- /stations/에 전국 TAGO 공식 도시코드 기반 역 목록, 17개 시·도 선택, 역명 검색과 더 보기를 추가했습니다. 기존 주요역 10곳은 빠른 바로가기로 유지합니다.
- 공식 역 API 응답에서 도시 이름·코드를 기준으로 지역을 분류합니다. 알 수 없는 지역은 미분류로 표시하고 임의 주소를 추정하지 않습니다. 제주 등 공식 목록에 역이 없는 지역은 비어 있을 수 있습니다.
- /stations/:id와 /routes/:from/:to는 공식 역 목록에서 확인되는 다른 역도 표시하지만 동적 미편집 페이지에는 noindex를 적용합니다. 공식 API의 운행 결과 없이 직통편·운임·중간 정차시간을 만들어 표시하지 않습니다.
- /api/stations?v=nationwide-regions-v1 응답은 region 필드를 포함하며 지역별 페이지를 최대 3장씩 가져오고 부분 누락 시 partial로 안내합니다. 공유되는 Cloudflare Cache를 사용합니다.
- 기존 기차·고속·시외·시내 API는 변경하지 않습니다. 실제 Cloudflare 운행 응답은 배포 후 확인합니다.

## 공식 배차가 없는 상세 구간 숨김 (2026-10-23)
- 역 상세페이지 추천 구간은 선택 날짜의 TAGO 시간표가 실제 1건 이상 조회된 경우에만 노출합니다. API 부분응답·통신 오류는 운행 없음으로 판단하지 않습니다.
- 다른 목적지 선택 시 시간표를 사전 조회해 0건이면 빈 상세페이지로 이동하지 않습니다. 날짜를 변경하면 추천 구간도 다시 검증합니다.
- 직접 URL로 접근한 구간에서 조회결과 0건이면 빈 표와 녹색 성공 문구를 숨기고 운행 미확인 안내를 표시합니다.
- 구간 상세 URL은 검증되지 않은 SEO 페이지가 색인되지 않도록 noindex 하고 사이트맵에서 제외합니다. API 통신량을 보호하려고 추천 구간 확인은 최대 2개 동시 수행합니다.

## 빈 조회 결과 숨김 공통 규칙
- 기차·고속·시외버스는 확인된 시간표가 1건 이상일 때만 결과 표를 표시합니다. 0건 또는 API 오류일 때는 검색 폼 근처에 사유를 명시하고 공식 예매처 링크를 유지합니다.
- 시내버스 정류장/노선 목록은 공식 등록 자체를 유지합니다. 실시간 도착정보 중 남은 시간이 미제공된 항목은 도착예정 목록에서 제외합니다. 현재 도착이 없어도 정류장을 삭제하거나 운행 종료를 단정하지 않습니다.
- 시내버스 검색에서 조회 결과가 비어 있는 페이지는 숨기지만 다음 페이지가 있을 때는 더 보기를 유지합니다.

## 2026-10-23 역별 검증된 구간만 노출
- 전국 모든 역을 표시하던 미검증 목적지 드롭다운 제거.
- 날짜별 TAGO API가 배차 1건 이상을 반환한 경우에만 브라우저에서 직통 구간 링크 생성. 빈 결과나 API 오류는 노출하지 않음.
- 기타 목적지는 기존 전체 기차 검색에서 별도로 조회 가능. API 오류는 운행 없음으로 판단하지 않음.

## 첫 화면 출발역 기반 도착역 제한 (2026-10-23)
- 출발역 선택 시 철도노선 기반 후보를 최대 18개로 제한하고, 날짜별 TAGO 직통 시간표가 실제 1건 이상 확인된 역만 도착역 자동완성에 표시합니다. 후보 API 조회는 최대 3개 동시 실행합니다.
- 선택 날짜 또는 열차종류 변경 시 검증을 갱신합니다. API가 오류/부분 결과/배차 0건을 반환하면 해당 목적지를 추천하지 않습니다. 이 기능은 완전한 전국 노선 목록이 아니며 누락 가능성을 UI에 명시합니다.
- 기본 모드는 검증된 목적지만 선택할 수 있고, 사용자가 명시적으로 전환하면 전국 역에서 수동 검색할 수 있습니다. 전체검색 모드에서도 직통 여부는 최종 검색 결과로 판단합니다.
